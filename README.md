## What I build

**Native macOS apps are my main focus.** Swift is where I spend most of my development time, especially when I’m building something I want to feel at home on the Mac.

I reach for Rust when an idea belongs in the terminal or needs to run across platforms. I also work on developer tooling and use TypeScript for web projects and Discord bots. A lot of what I build stays private while I work on it. I put it out when I’m happy with it.

## Stack

| Area | What I use |
| :--- | :--- |
| **Native macOS** | **Swift**, my main language |
| **CLI and systems** | Rust for command-line tools and cross-platform software |
| **Web** | TypeScript and Astro, plus React in Atrium |
| **Discord bots** | Serenity in Rust and discord.js in TypeScript |
| **Learning** | C and C++ to understand memory, compilation, and what happens at runtime |

## Open source

**[Atrium](https://github.com/itssljk/atrium)** · A customizable browser start page · **[20 merged PRs](https://github.com/itssljk/atrium/pulls?q=is%3Apr+is%3Amerged+author%3Aitssuross)**

I worked across search, accessibility, and settings. That included making [search suggestions work with the keyboard](https://github.com/itssljk/atrium/pull/30), testing [search contrast over wallpapers](https://github.com/itssljk/atrium/pull/28) across 42 desktop cases, and making [backup restores reject malformed shortcuts](https://github.com/itssljk/atrium/pull/32) before writing settings.

## The long-term project

> I want to build a programming language of my own, from the syntax and parser through the compiler and runtime.

I have a rough idea of what I want the language to do. I’m still figuring out what it should feel like to write in it.
